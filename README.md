# Basic Calculator

This repository contains a small Swing-based calculator application. It was originally created with IntelliJ IDEA's GUI designer.

## Requirements

- **JDK 19 or later** – the project was configured to use JDK 19. Any recent JDK should work, but compiling with an older version may require adjustments.
- A system with graphical support (the application opens a Swing window).

## Compiling

From the repository root, run:

```bash
javac -d out src/*.java
```

This compiles the `Main` and `calculator` classes into the `out` directory.

## Running

Run the calculator with:

```bash
java -cp out Main
```

The program launches a simple GUI where you can perform basic arithmetic operations.

## Notes

The UI layout is defined in `src/calculator.form` and was generated by IntelliJ IDEA. Only the `.java` files need to be compiled.
